How to Embed a Video into Your website

01. Find your video

Navigate to the video you want to share and locate the "Share button, usually found right below the video player

02. Access the embed menu

Click the "Share" button and select the "Embed"option from the pop up menu.

03. Copy the code

Awindow will apear with HTML code. Click the "Copy" button to save the iframe code to your clipboard.

04. Paste into your HTML

Open your HTML file and paste the code into the <body> section where you want the video to appear.

05. Apply CSS

Use your External CSS file to Adjujst the width and height of the iframe to fit your sit'es layout.
